# 04. Copula 기반 시장·신용·운영리스크 통합 분석

## 프로젝트 개요
개별적으로 산출된 시장리스크(VaR), 신용리스크(PD/ECL), 운영리스크(LDA) 3개 모듈을
Copula를 이용해 결합분포로 통합하고, 리스크 간 의존구조(특히 위기 국면의 동반붕괴,
꼬리의존성)를 반영했을 때 통합 필요자본이 어떻게 달라지는지 정량적으로 검증한 분석입니다.

## 분석 배경 및 목적
개별 리스크를 단순 합산하면 리스크 간 분산효과를 완전히 무시하게 되고,
반대로 상관계수(선형 상관)만 반영하는 Gaussian copula는 평상시 관계는 잘 잡아내지만
위기 국면에서 리스크들이 동시에 급격히 악화되는 "꼬리의존성(tail dependence)"을
과소평가하는 한계가 있습니다. 본 분석은 이 두 접근법의 차이를 실제 숫자로 비교해,
Gaussian 가정만으로 자본을 산출할 경우 발생할 수 있는 과소평가 위험을 검증했습니다.

## 데이터
- 10년치(2,520 영업일) 일별 시장수익률(t분포, 팻테일), 신용리스크(감마분포, 시장과 40% 연동),
  운영리스크(포아송-로그정규 LDA) 시뮬레이션 데이터를 월별로 집계 (120개월)
- 매월 5% 확률로 위기 국면(systemic crisis)이 발생하도록 공통 증폭요인을 추가해,
  실제 금융위기 시 세 리스크가 동시에 악화되는 현상을 반영

## 방법론
1. **마진분포 균일화(PIT)**: 각 리스크를 순위 기반 의사관측치(pseudo-observation, 0~1)로 변환
2. **Gaussian Copula 적합**: 표준정규 역변환 후 상관행렬 추정
3. **t-Copula 적합**: 상관행렬은 동일하게 사용(IFM 방식)하고, 자유도(ν)는 최대우도추정(MLE)으로 별도 추정
4. **모델 비교**: 로그우도 및 자유도 크기로 꼬리의존성 유의성 검증
5. **몬테카를로 결합 시뮬레이션**: 각 코풀라에서 10만 회 시뮬레이션 후 경험적 분위함수로
   실제 손실 단위로 역변환, 세 리스크 합산하여 99% VaR 산출

## 주요 결과

| 구분 | 값 |
|---|---|
| t-Copula 최적 자유도(ν) | 5.23 |
| 로그우도 차이 (t − Gaussian) | +3.00 |
| 단순합산 VaR (완전상관 가정) | 1.858 |
| Gaussian Copula 통합 VaR | 1.218 (분산효과 34.4%) |
| t-Copula 통합 VaR | 1.280 (분산효과 31.1%) |
| **Gaussian 대비 t-Copula 추가 필요자본** | **+5.1%** |

## 시사점
- 자유도 5.23은 뚜렷한 꼬리의존성을 의미하며, 로그우도 비교에서도 t-Copula가 통계적으로
  더 우수한 적합도를 보여 이 데이터에는 Gaussian보다 t-Copula가 적합한 모델임을 확인
- Gaussian copula 기준으로만 자본을 산출할 경우, 위기 국면의 동반 리스크를 반영한
  t-Copula 대비 필요자본을 약 5.1% 과소평가하는 것으로 나타남
- 이는 바젤 프레임워크 및 ICAAP(내부자본적정성평가)에서 상관관계 가정에 대한
  스트레스 테스트를 별도로 요구하는 이유와 직접적으로 연결됨

## 한계점
- 실제 금융데이터가 아닌 시뮬레이션 데이터를 사용했으며, 위기 국면 발생 확률·강도는
  임의로 설정한 가정값임
- 상관행렬과 자유도를 동시에 최적화(FML)하지 않고 2단계 추정(IFM)을 사용해 근사함
- 대칭적 꼬리의존성만 반영하는 t-Copula 특성상, 상방/하방 비대칭 위험(예: Clayton,
  Gumbel copula가 포착하는 편측 꼬리의존성)은 다루지 않음
