# Risk Management Portfolio

리스크관리 직무 역량 강화를 위해 시장리스크, 신용리스크, 운영리스크 세 영역을 정량분석한 개인 프로젝트입니다. 각 모듈은 실제(또는 실무 표준 방법론에 기반한) 데이터를 활용해 리스크를 측정하고, 모델을 검증하며, 그 한계까지 짚어보는 것을 목표로 합니다.

## 폴더 구조

```
risk-management-portfolio/
├── 01-market-risk/         시장리스크: VaR 산출 및 검증
├── 02-credit-risk/         신용리스크: PD 모델링 및 IFRS9 ECL
├── 03-operational-risk/    운영리스크: LDA 및 KRI 모니터링
└── README.md                (현재 파일)
```

각 폴더에는 분석 결과를 정리한 `README.md`와, 실제 코드·실행 결과가 담긴 Colab 노트북(`.ipynb`)이 함께 들어 있습니다.

## 모듈 요약

### [01. 시장리스크](./01-market-risk)
KOSPI200 데이터로 Historical Simulation과 Variance-Covariance 두 방식의 VaR을 산출하고 Kupiec test로 백테스팅했다. Historical Simulation은 두 신뢰수준 모두 통계적으로 적합했으나, 정규분포를 가정한 Variance-Covariance 방식은 기각되어 실제 수익률 분포의 fat tail 특성을 확인했다. 코로나 폭락기 스트레스 테스트 결과, 최악의 하루 손실이 99% VaR 예상치를 상회해 정상 시장 가정의 한계도 함께 검증했다.

### [02. 신용리스크](./02-credit-risk)
개인신용대출 데이터로 로지스틱 회귀 기반 PD(부도확률) 모델을 구축했다(ROC-AUC 0.801, KS 0.479). IFRS9 기준 Stage를 분류해 12개월/Lifetime 기대손실(ECL)을 산출한 결과, 소수의 고위험(Stage 2) 대출자가 전체 포트폴리오 기대손실의 대부분을 차지함을 확인했다. 모델 변수 해석 과정에서 반직관적 결과와 공정성(fairness) 이슈도 함께 짚었다.

### [03. 운영리스크](./03-operational-risk)
손실분포접근법(LDA)으로 빈도(포아송)·심도(로그정규) 분포를 추정하고, 몬테카를로 시뮬레이션으로 99.9% 신뢰수준의 운영리스크 자기자본을 산출했다. 단순 지표법인 바젤 기초지표법(BIA)과 비교한 결과 LDA 기준 자본이 278% 더 크게 나와, 규모 기반의 단순 방식이 fat tail 리스크를 과소평가할 수 있음을 보였다. 핵심리스크지표(KRI) 대시보드로 사전적 모니터링 체계도 함께 구성했다.

## 사용 기술

`Python` `pandas` `numpy` `scipy` `scikit-learn` `matplotlib`

## 핵심적으로 얻은 인사이트

- 정규분포 가정 기반 리스크 모델은 실제 금융시장의 fat tail 특성을 제대로 반영하지 못하며, 통계적 백테스팅을 통해 이를 실증적으로 검증할 수 있다.
- 리스크관리의 핵심은 전체 평균을 관리하는 것이 아니라, 위험이 커지는 소수(Stage 2 채권, 극단 손실 사건 등)를 얼마나 빠르고 정확하게 식별하는가에 있다.
- 정교한 통계 모델과 단순 지표법 사이의 자본 산출 차이는 상당히 크며, 방법론 선택이 실제 리스크관리 의사결정에 미치는 영향이 크다.
