# Risk Management Learning Portfolio
### FRM 기반 리스크관리 이론의 데이터 분석 적용 학습

## 1. 프로젝트 소개

본 저장소는 FRM(Financial Risk Manager) 학습 과정에서 습득한 리스크관리 이론과 모형이 실제 데이터 분석에 어떻게 적용될 수 있는지 탐색하고 이해하기 위해 시작한 개인 학습 프로젝트입니다.

금융기관에서 근무하며 리스크관리 직무에 관심을 갖게 되었고, FRM 자격 취득 이후에는 이론적 지식을 실제 분석 과정과 연결하여 이해하고자 했습니다.

시장리스크, 신용리스크, 운영리스크 등 다양한 영역을 대상으로 공개데이터와 가상데이터를 활용해 분석 사례를 구성하였습니다.

**본 프로젝트의 주된 목적은 독립적인 프로그래밍 역량이나 실무 수준의 모형개발 능력을 입증하는 것이 아니라, 리스크관리 이론이 데이터 분석 과정에서 어떻게 구현되고 활용될 수 있는지 학습하는 데 있습니다.**

## 2. AI 활용 및 프로젝트 수행 방식

본 저장소의 프로젝트들은 생성형 AI의 적극적인 도움을 받아 진행하였습니다.

Python 및 SQL을 활용한 분석 구조 설계, 코드 작성, 데이터 처리, 시각화 등 기술적 구현 과정에서 AI의 도움을 크게 받았으며, 해당 코드들을 모두 독립적으로 설계하거나 직접 작성한 것은 아닙니다.

저는 FRM에서 학습한 개념들이 실제 분석에 어떻게 적용될 수 있는지 탐색하는 것을 목표로 프로젝트를 진행하였습니다.

따라서 본 저장소의 결과물은 독립적으로 개발한 실무용 분석 시스템이라기보다, **AI를 활용해 리스크관리 이론의 적용 사례를 살펴보고 학습하기 위한 결과물**로 이해해 주시면 감사하겠습니다.

현재는 기존 분석의 목적과 결과를 이해하는 수준에서 나아가, SQL을 중심으로 데이터 처리와 분석 과정을 직접 구현하고 검증할 수 있도록 학습하고 있습니다.

## 3. 주요 학습 영역

| 영역 | 주요 학습 주제 |
|---|---|
| 시장리스크 | VaR, ES, Backtesting, EVT/GPD |
| 신용리스크 | PD, LGD, EAD, IFRS9 ECL, 연체 분석 |
| 운영리스크 | LDA, KRI, 손실분포 분석 |
| 통합리스크 | Copula, 리스크 간 의존구조 |
| 모형 검증 | ROC-AUC, KS, Calibration, PSI |
| 데이터 분석 | Python 및 SQL 기반 데이터 처리·집계·분석 |

각 프로젝트에서는 분석의 목적, 적용된 리스크관리 개념, 주요 결과와 한계를 중심으로 내용을 정리하였습니다.

분석 결과는 사용된 데이터와 가정에 따라 달라질 수 있으며, 실제 금융기관의 모형 성능이나 리스크 수준을 의미하지 않습니다.

## 4. 향후 학습 방향

현재는 SQL을 중심으로 데이터 분석 역량을 강화하고 있습니다.

기존 프로젝트에서 활용한 분석 과정을 다시 살펴보며, 데이터 추출과 가공, 리스크 지표 산출, 분석 결과 검증 등을 직접 수행할 수 있는 역량을 갖추는 것이 목표입니다.

특히 신용리스크 및 금융기관의 포트폴리오 모니터링과 관련된 분석을 우선적으로 학습하고자 합니다.

앞으로는 단순히 분석 결과물을 추가하기보다, **분석 과정과 코드를 충분히 이해하고 직접 설명할 수 있는 프로젝트를 축적하는 것**에 중점을 둘 계획입니다.

## 5. 마무리

본 저장소는 완성된 리스크관리 분석 역량을 보여주기 위한 포트폴리오라기보다, FRM을 통해 습득한 이론적 지식을 실제 데이터 분석과 연결해 나가는 학습 기록입니다.

AI를 활용한 초기 탐색 단계에서 출발했지만, 앞으로는 직접 분석하고 검증할 수 있는 역량을 점진적으로 쌓아가고자 합니다.

리스크관리 분야에 대한 지속적인 관심과 학습 과정을 기록하는 공간으로 발전시켜 나가겠습니다.
