# 06. 유동성리스크 — LCR/NSFR 스트레스 테스트

## 프로젝트 개요
가상 은행의 재무상태표를 바젤III 기준에 맞춰 설계하고, 유동성커버리지비율(LCR)과
순안정자금조달비율(NSFR)을 산출한 뒤, 예금 대량인출(뱅크런) 시나리오를 단계별로
적용해 평상시 여유로워 보이는 유동성 지표가 위기 국면에서 실제로 얼마나
빠르게 붕괴하는지 정량적으로 검증한 분석입니다.

## 분석 배경 및 목적
LCR·NSFR은 바젤III의 핵심 유동성 규제지표로, 은행 리스크관리 실무에서 일일
단위로 모니터링하는 항목입니다. 평상시 지표만 보면 규제기준을 넉넉히 충족하는
것처럼 보이지만, 신용등급 강등이나 SNS발 예금인출 같은 사건이 실제로는
단기간에 유동성을 크게 악화시킬 수 있습니다. 본 분석은 이 격차를 스트레스
시나리오로 직접 계산해 보여주는 데 목적을 두었습니다.

## 데이터
- 총자산 10조원(100,000억원) 규모의 가상 중형 은행 재무상태표를 바젤III 기준
  자산 유동성 등급(HQLA Level 1/2A/2B)과 부채 유출가중치 체계에 맞춰 설계
- 실제 은행 내부 데이터는 외부에서 접근 불가능해 시뮬레이션 데이터를 사용했으며,
  국내 인터넷은행 규모감과 예금 구조(안정적 개인예금·불안정 온라인예금·기업예금·
  도매조달)를 참고해 현실적으로 구성

## 방법론
1. **LCR 산출**: HQLA(가중치 100%/85%/50%)를 향후 30일 순현금유출액(부채 항목별
   유출률 - 인정 현금유입, 유입은 유출의 75%까지만 인정)으로 나눠 계산
2. **NSFR 산출**: 가용안정자금(ASF, 조달원 안정성별 가중치)을 필요안정자금(RSF,
   자산 유동화 난이도별 가중치)으로 나눠 계산
3. **스트레스 시나리오 4단계**: 평상시 → 경미한 스트레스(금리인상 우려) → 심각한
   스트레스(신용등급 강등) → 뱅크런급(SNS발 대량인출), 단계가 심화될수록 특히
   불안정 예금·기업예금의 유출률을 현실적으로 상향 조정

## 주요 결과

| 시나리오 | LCR | 규제기준(100%) 충족 여부 |
|---|---|---|
| 평상시 | 154.3% | 충족 |
| 경미한 스트레스 (금리인상 우려) | 113.1% | 충족 |
| 심각한 스트레스 (신용등급 강등) | **72.4%** | **미충족** |
| 뱅크런급 (SNS발 대량인출) | 50.4% | 미충족 |

| 지표 | 값 |
|---|---|
| NSFR (평상시 기준) | 118.7% (충족) |

## 시사점
- 평상시 LCR 154.3%는 규제기준 대비 매우 여유로워 보이지만, "심각한 스트레스"
  단계(신용등급 강등 수준)만으로도 규제기준을 밑도는 72.4%까지 붕괴함 — 이는
  정적인 평상시 지표만으로는 유동성 리스크를 충분히 관리할 수 없으며, 정기적인
  스트레스 테스트가 필수적임을 정량적으로 보여줌
- 온라인전용 예금처럼 모바일 앱으로 즉시 이체 가능한 자금원은 위기 시 유출률이
  전통적 예금보다 훨씬 가파르게 상승하는 것으로 가정했으며, 이는 핀테크·
  인터넷은행이 전통 은행보다 유동성 리스크 관리에 더 민감해야 하는 구조적
  이유와 연결됨
- LCR(단기)은 위기 시나리오에서 취약한 반면 NSFR(장기 조달구조)은 상대적으로
  안정적으로 유지되어, 단기 유동성 관리가 이 은행 구조에서 상대적으로 더 시급한
  과제임을 시사함

## 한계점
- 실제 은행 재무상태표가 아닌 시뮬레이션 데이터를 사용했으며, 자산·부채
  비중과 스트레스 시나리오의 유출률 가정은 바젤III 기준을 참고해 임의로
  설정한 값임
- 단일 시점(정적) 재무상태표를 기준으로 한 분석으로, 실제 규제상의 LCR은
  일별로 변동하는 동적 지표이며 이 분석은 그 변동성을 반영하지 않음
- 자산·부채 항목을 실제 은행 공시보다 단순화해 구성했으며, 파생상품·
  담보콜(collateral call) 등 추가 유동성 소요 요인은 포함하지 않음
