# 07. 이상거래(사기) 탐지 — Isolation Forest 기반 실시간 이상탐지

## 프로젝트 개요
Kaggle의 실제 유럽 카드사 익명화 거래데이터(284,807건, 사기거래 492건)를 활용해
비지도학습 기반 이상탐지 모델(Isolation Forest)을 구축하고, 극심하게 불균형한
데이터에서 탐지율(Recall)과 정밀도(Precision)가 임계값에 따라 어떻게 상충되는지
정량적으로 분석한 프로젝트입니다. 03-operational-risk의 손실분포 접근(LDA)이
"사후적으로 손실을 추정"하는 방식이었다면, 이번 모듈은 핀테크 실무에서 요구되는
"사전적·실시간 이상거래 탐지"를 재현했습니다.

## 분석 배경 및 목적
핀테크는 거래량이 많고 실시간 이상탐지가 운영리스크 관리의 핵심 영역입니다.
실제 사기 데이터는 극히 드물게 발생(전체의 0.17%)해 지도학습에 필요한 라벨이
충분치 않은 경우가 많아, 정상 패턴에서 벗어난 거래를 라벨 없이 자동 탐지하는
비지도학습 접근이 실무에서 널리 쓰입니다. 본 분석은 이 접근법의 실제 성능과
한계, 그리고 운영상 임계값 설정이 왜 정책적 판단인지를 데이터로 보여주는 데
목적을 두었습니다.

## 데이터
- Kaggle "Credit Card Fraud Detection" 데이터셋(mlg-ulb/creditcardfraud):
  2013년 9월 유럽 카드사용자의 실거래 284,807건, 사기거래 492건(0.1727%)
- V1~V28은 원본 거래정보(가맹점·위치 등 민감정보)를 PCA로 익명화한 값이며,
  Time(경과초)·Amount(거래금액)·Class(사기여부)는 원본 그대로 제공됨

## 방법론
1. **탐색적 분석**: 정상 대비 사기거래의 금액 분포(소액 테스트성 거래·특정
   금액대 스파이크) 및 시간대별 발생 패턴(새벽 시간대 집중) 확인
2. **전처리**: Amount, Time을 표준화(StandardScaler)해 이미 PCA로 표준화된
   V1~V28과 스케일을 맞춤
3. **모델링**: Isolation Forest(비지도학습, 라벨 미사용)로 이상치 점수 산출 —
   나무 200개, contamination 0.002
4. **평가**: 불균형 데이터에 적합한 PR-AUC(Average Precision)를 핵심 지표로
   사용, ROC-AUC와 비교해 불균형 데이터에서 각 지표의 함의 차이를 검증
5. **임계값 트레이드오프 분석**: 상위 0.05%~1% 구간에서 탐지율-정밀도 변화를
   계산해 운영 임계값 설정의 실무적 의사결정 근거를 제시

## 주요 결과

| 지표 | 값 |
|---|---|
| ROC-AUC | 0.9474 |
| PR-AUC (Average Precision) | 0.1635 (랜덤 기준선 0.0017 대비 약 96배) |

| 상위 % (이상거래 분류 기준) | 탐지율(Recall) | 정밀도(Precision) | 플래그 건수 |
|---|---|---|---|
| 1.00% | 56.9% | 9.8% | 2,849건 |
| 0.50% | 43.7% | 15.1% | 1,425건 |
| 0.30% | 35.4% | 20.4% | 855건 |
| 0.20% | 28.0% | 24.2% | 570건 |
| 0.10% | 21.1% | 36.5% | 285건 |
| 0.05% | 12.2% | 42.0% | 143건 |

## 시사점
- **ROC-AUC(0.9474)와 PR-AUC(0.1635)의 큰 격차가 이 프로젝트의 핵심 발견**:
  극단적으로 불균형한 데이터에서는 ROC-AUC가 실제 성능을 과대평가할 수 있으며,
  PR-AUC가 훨씬 정직한 지표임을 실증적으로 확인함. 사기탐지·이상탐지처럼
  양성 클래스가 극소수인 문제에서는 평가지표 선택 자체가 모델 성능 판단을
  좌우할 수 있음
- 라벨을 전혀 사용하지 않은 비지도학습임에도 이상치 점수 분포에서 사기거래가
  정상거래보다 명확히 높은 쪽에 위치해, 신종·미라벨링 사기패턴 탐지 가능성을
  뒷받침함
- 임계값을 상위 1%로 넓히면 탐지율은 오르지만 정밀도가 9.8%까지 떨어져 실제
  운영시 오탐(정상고객 불편, 상담인력 부담)이 급증함 — 임계값 설정은 순수한
  통계적 결정이 아니라 탐지력과 운영비용 사이의 정책적 트레이드오프임을
  구체적 수치로 확인함

## 한계점
- 2013년 유럽 카드데이터로, 국내 핀테크의 실제 거래패턴·사기유형과는 차이가
  있을 수 있음
- V1~V28이 PCA 익명화되어 있어 어떤 원본 변수가 탐지에 기여했는지 해석이
  제한적임(모델의 설명가능성 한계)
- 단일 모델(Isolation Forest)만 사용했으며, Autoencoder 등 다른 비지도학습
  기법과의 비교는 후속 과제로 남김
- 정적 데이터셋 기반 분석으로, 실시간 스트리밍 환경에서의 지연시간·처리량
  등 운영 요구사항은 다루지 않음
