# 08. 카드사 특화 신용리스크 — 카드대손/연체 예측 모델

## 프로젝트 개요
대만 신용카드사의 실제 개인단위 거래데이터(3만 건)를 활용해, 카드 이용자의
결제행동 패턴(연체 이력, 리볼빙 성향, 한도소진율)으로부터 다음달 채무불이행
여부를 예측하는 모델을 구축한 분석입니다. 05-sme-credit-scoring이 기업
재무제표 기반 PD 모델이었다면, 이번 모듈은 카드사 신용리스크 실무의 핵심인
개인 카드 이용자의 결제행동 데이터 기반 접근을 재현했습니다.

## 분석 배경 및 목적
카드사 신용리스크는 재무제표가 아닌 카드 이용자의 결제행동(청구액 대비
실제 결제액, 연체 이력, 한도 사용 패턴)으로 부실 위험을 판단하는 구조라
기업 신용평가와는 접근 방식이 근본적으로 다릅니다. 본 분석은 원본 결제
데이터를 실무에서 쓰이는 행동패턴 지표로 가공하고, 표본 크기가 충분히 클 때
지도학습 모델(로지스틱 회귀 vs XGBoost)의 성능 차이가 어떻게 나타나는지도
함께 검증했습니다.

## 데이터
- Kaggle "Default of Credit Card Clients Dataset"(UCI 원본): 대만 신용카드사
  실제 개인 이용자 30,000명, 다음달 채무불이행 비율 22.12%(6,636명)
- 원본 변수: 신용한도, 인구통계(성별·학력·혼인·나이), 최근 6개월 월별
  결제상태·청구금액·결제금액

## 방법론
1. **피처 엔지니어링**: 원본 월별 데이터를 행동패턴 지표로 가공
   - 최근 연체 심각도(recent_delay), 최근 6개월 최대 연체개월수(max_delay_6m)
   - 6개월 중 연체 발생 빈도(delay_freq_6m)
   - 평균 결제비율(avg_payment_ratio, 청구액 대비 실제 결제액 — 리볼빙 성향 지표)
   - 평균 한도소진율(avg_utilization, 청구액 대비 신용한도)
2. **탐색적 검증**: 채무불이행 여부에 따른 각 지표의 분포 차이를 확인해
   경제적 직관과의 일치 여부 검증
3. **모델링**: 로지스틱 회귀(class_weight='balanced')와 XGBoost
   (scale_pos_weight 적용)를 학습·비교
4. **평가**: ROC-AUC, KS statistic, 피처 중요도 분석

## 주요 결과

| 구분 | 값 |
|---|---|
| 표본 | 30,000명 (학습 21,000 / 검증 9,000), 채무불이행 비율 22.12% |
| 로지스틱 회귀 | ROC-AUC 0.745, KS 0.393 |
| XGBoost | ROC-AUC 0.766, KS 0.412 |
| 최상위 예측변수 | max_delay_6m (중요도 61.8%), recent_delay (21.4%) |

## 시사점
- **05번(SME) 모듈과 정반대 결과**: SME 모듈은 부실표본이 34건뿐이라
  XGBoost가 랜덤 수준(AUC 0.497)으로 무너졌던 반면, 이번엔 표본이
  충분히 커서(불이행 6,636건) XGBoost가 로지스틱 회귀를 확실히
  앞섬(0.766 vs 0.745). 두 프로젝트를 비교하면 "표본 크기가 모델
  복잡도 선택을 좌우한다"는 원칙을 실증적으로 다시 확인함
- 연체 이력 관련 두 변수(max_delay_6m, recent_delay)가 전체 예측력의
  83%를 차지해, 카드업계에서 통용되는 "최근 연체 이력이 가장 강력한
  부실 예측 신호"라는 실무 통설과 정확히 일치함
- 한도소진율은 채무불이행 그룹에서 유의미하게 높게 나타나(중앙값 0.47 vs
  0.24) 재무적 여유가 적을수록 부실 위험이 커진다는 직관을 뒷받침하지만,
  모델 기여도 자체는 연체 이력 대비 크지 않아 보조지표로서의 성격이 강함
- 평균 결제비율(리볼빙 성향 지표)은 채무불이행 그룹에서 뚜렷이 낮게
  나타나(0.27 vs 0.46) 최소금액만 결제하는 패턴이 부실의 선행신호임을
  확인함

## 한계점
- 대만 카드사 2005년 데이터로, 국내 카드업계의 실제 연체 패턴·상품 구조와는
  차이가 있을 수 있음
- 최근 6개월이라는 짧은 관측기간만 사용했으며, 장기 결제이력이나 다른
  금융기관 신용정보(CB사 데이터)는 반영하지 않음
- 인구통계 변수(성별·학력·혼인)는 이번 모델링에서 제외했는데, 이는 차별
  소지가 있는 변수의 사용을 신중히 검토해야 한다는 실무 관점을 반영한
  것이며 예측력 손실 여부는 별도로 검증하지 않음
