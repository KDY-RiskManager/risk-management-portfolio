# 시장리스크 분석 — SQL 버전 (MySQL)

[Python으로 진행한 VaR 분석](../README.md)을 **MySQL SQL로 다시 구현**하고, 두 결과가 일치하는지 검증한 프로젝트입니다.

## 목적

리스크관리 직무에서 SQL이 공통적으로 요구되는 점을 고려해, 기존 분석을 SQL로 직접 재현하며 SQL 활용 능력을 키우는 것을 목표로 했습니다.

## 학습 방법

SQL을 학습하는 과정에서 **AI(Claude)를 학습 보조 도구로 활용**했습니다.

- 쿼리 설계 방향과 SQL 문법(윈도우 함수, CTE, VIEW 등)을 AI와 대화하며 학습
- 작성된 쿼리를 셀 단위로 실행하고, 각 구문이 어떤 의미인지 확인하며 진행
- AI가 만든 결과를 그대로 믿지 않고, **기존 Python 분석 결과와 직접 대조해 검증**
- MySQL에는 `PERCENTILE_CONT`가 없는 점 등, 실행 환경의 제약을 확인하고 대안을 적용

## 분석 개요

| 항목 | 내용 |
|---|---|
| 데이터 | KOSPI200 일별 종가 (FinanceDataReader) |
| VaR 산출 기간 | 2021-01-01 ~ 2026-08-01 (수익률 1,366개) |
| 포트폴리오 가정 | 1억원 |
| 방법 | Historical Simulation / Variance-Covariance, Kupiec 백테스팅, 스트레스 테스트 |

Python은 데이터 적재에만 사용했고, 수익률 계산부터 VaR, 백테스팅, 스트레스 테스트까지는 SQL로 수행했습니다.

## 사용한 SQL 기능

| 단계 | 주요 SQL 기능 |
|---|---|
| 일별 수익률 | `LAG()` 윈도우 함수, `VIEW` |
| Historical VaR | `ROW_NUMBER()`, `CTE`, 선형보간 |
| Parametric VaR | `AVG()`, `STDDEV_SAMP()` |
| Kupiec 백테스팅 | `SUM(조건)`, `UNION ALL`, `LN()`, `CASE WHEN` |
| 스트레스 테스트 | 기간 조인, `MIN()`, `GROUP BY` |

## 결과

### VaR (하루 예상 손실액, 1억원 기준)

| 신뢰수준 | Historical | Variance-Covariance |
|---|---|---|
| 95% | 2,225,137원 | 2,972,151원 |
| 99% | 6,083,087원 | 4,239,916원 |

### Kupiec 백테스팅

| 모델 | 신뢰수준 | 예외 횟수 | 기대 횟수 | LR 통계량 | 판정 |
|---|---|---|---|---|---|
| Historical | 95% | 69 | 68.3 | 0.0075 | 적합 |
| Historical | 99% | 14 | 13.7 | 0.0085 | 적합 |
| Variance-Covariance | 95% | 39 | 68.3 | 15.5495 | 기각 |
| Variance-Covariance | 99% | 25 | 13.7 | 7.6356 | 기각 |

LR 통계량이 카이제곱 임계값(3.841, 자유도 1, 유의수준 5%)을 넘으면 기각했습니다.

### 스트레스 테스트

| 시나리오 | 하루 최대 손실 | 평상시 99% VaR | 비교 |
|---|---|---|---|
| 코로나 폭락 (2020-02-19 ~ 03-19) | 7,668,072원 | 6,083,087원 | VaR 초과 |
| 2022년 금리인상기 | 3,512,826원 | 6,083,087원 | VaR 이내 |

### Python vs SQL 교차검증

| 항목 | Python | SQL | 일치 |
|---|---|---|---|
| Historical VaR 95% / 99% | 약 220만원 / 610만원 | 2,225,137원 / 6,083,087원 | O |
| 예외 횟수 (Historical 95% / 99%) | 69회 / 14회 | 69회 / 14회 | O |
| 예외 횟수 (Var-Cov 95% / 99%) | 39회 / 25회 | 39회 / 25회 | O |
| Kupiec 판정 | Historical 적합, Var-Cov 기각 | 동일 | O |
| 스트레스 (코로나 / 금리인상기) | 약 770만원 / 350만원 | 7,668,072원 / 3,512,826원 | O |

## 배운 점

- 같은 분석이라도 SQL로 하면 계산이 DB 안에서 끝나, 실무의 리스크 지표 산출 구조와 가깝다는 점을 체감
- 윈도우 함수(`LAG`, `ROW_NUMBER`)와 CTE로 복잡한 계산을 단계별로 나눠 읽기 쉽게 만드는 방법을 익힘
- Variance-Covariance는 95%에서 리스크를 과대평가하고 99%에서 과소평가해, 수익률 분포가 정규분포보다 꼬리가 두껍다는 점을 SQL 결과로도 확인
