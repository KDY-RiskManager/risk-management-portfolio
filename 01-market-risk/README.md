# 시장리스크(Market Risk) 분석 — VaR 모델링 및 검증

KOSPI200 지수 데이터를 활용해 시장리스크를 정량화하고, 두 가지 VaR 산출 방식을 비교·검증한 프로젝트입니다.

## 프로젝트 개요

- **목적**: 실제 시장 데이터를 활용해 Value at Risk(VaR)를 산출하고, 모델의 통계적 유효성을 검증
- **분석 대상**: KOSPI200 지수 일별 수익률
- **핵심 질문**:
  1. VaR을 어떻게 산출하며, 방법론에 따라 결과가 어떻게 달라지는가?
  2. 산출된 VaR 모델이 실제 시장 데이터와 통계적으로 부합하는가? (백테스팅)
  3. 평상시 통계 기반 VaR이 실제 위기 상황에서도 유효한가? (스트레스 테스트)

## 사용 데이터

| 항목 | 내용 |
|---|---|
| 데이터 소스 | FinanceDataReader (KOSPI200, 'KS200') |
| VaR 산출 기간 | 2021-01-01 ~ 2026-08-01 |
| 스트레스 테스트 기간 | 2019-01-01 ~ 2023-12-31 (코로나 폭락기, 2022년 금리인상기 포함) |

## 분석 방법론

### 1. VaR 산출 (2가지 방식 비교)
- **Historical Simulation**: 과거 수익률 데이터를 그대로 정렬해 하위 5%/1% 분위수로 VaR 산출
- **Variance-Covariance (Parametric)**: 수익률이 정규분포를 따른다고 가정하고 평균·표준편차 기반으로 VaR 산출

### 2. 백테스팅 — Kupiec Test
산출된 VaR을 초과하는 손실이 실제로 이론적 기대 빈도만큼 발생했는지 우도비 검정(Likelihood Ratio Test)으로 검증

### 3. 스트레스 테스트
코로나19 폭락기(2020.02.19~03.19), 2022년 금리인상기(2022.01~09) 두 시나리오에서 실제 발생한 손실을 VaR 예상치와 비교

## 주요 결과

### VaR 산출 결과 (포트폴리오 1억원 가정, 하루 예상 손실액)

| 신뢰수준 | Historical Simulation | Variance-Covariance |
|---|---|---|
| 95% | 약 220만원 | 정규분포 가정상 더 보수적으로 산출됨 |
| 99% | 약 610만원 | 정규분포 가정상 과소평가됨 |

### Kupiec Test 백테스팅 결과

| 모델 | 신뢰수준 | 예외 횟수 | p-value | 판정 |
|---|---|---|---|---|
| Historical Simulation | 95% | 69회 | 0.9309 | 모델 적합 |
| Historical Simulation | 99% | 14회 | 0.9266 | 모델 적합 |
| Variance-Covariance | 95% | 39회 | 0.0001 | 모델 기각 |
| Variance-Covariance | 99% | 25회 | 0.0057 | 모델 기각 |

### 스트레스 테스트 결과 (하루 최대 손실액)

| 시나리오 | 손실액 |
|---|---|
| 95% VaR (평상시) | 약 220만원 |
| 99% VaR (평상시) | 약 610만원 |
| 코로나 폭락 (2020.02.19~03.19) | 약 770만원 |
| 2022년 금리인상기 | 약 350만원 |

## 핵심 인사이트

1. **Historical Simulation이 통계적으로 더 신뢰할 만한 모델로 확인됨.** Kupiec test에서 95%, 99% 신뢰수준 모두 통과했다.
2. **Variance-Covariance(정규분포 가정) 방식은 두 신뢰수준 모두 기각됨.** KOSPI200 수익률 분포가 정규분포보다 첨도가 높고 꼬리가 두꺼운(leptokurtic) 특성을 보이기 때문으로, 95%에서는 리스크를 과대평가(예외 과소 발생), 99%에서는 극단 손실을 과소평가(예외 과다 발생)하는 상반된 오차 패턴이 나타났다.
3. **평상시 VaR 모델은 극단적 위기 상황에서 한계가 있다.** 코로나 폭락 당시 최악의 하루 손실(약 770만원)은 99% VaR 예상치(약 610만원)마저 상회했다. 이는 VaR과 별도로 시나리오 기반 스트레스 테스트가 병행되어야 함을 실증적으로 보여준다.
