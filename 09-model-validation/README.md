# 09. PD 모델 검증(Validation) — 08번 카드사 신용리스크 모델 사후검증

## 프로젝트 개요
08-card-credit-risk에서 구축한 카드사 신용리스크 XGBoost 모델을 대상으로,
은행권 표준 모델검증 프레임워크(변별력·캘리브레이션·모집단 안정성)를 적용한
사후검증 프로젝트입니다. 모델을 "만드는" 역량에서 나아가, 만들어진 모델이
운영 환경에서도 신뢰할 수 있는지 "검증하는" 역량을 별도로 다루었습니다.

## 분석 배경 및 목적
좋은 예측 모델도 시간이 지나거나 새로운 데이터에 적용되면 성능이 저하될 수
있어, 은행·카드사는 모델을 배포한 뒤에도 정기적으로 검증을 수행합니다. 본
분석은 08번 모델을 대상으로 실제 시간 흐름 데이터가 없는 한계를 감안해,
데이터를 개발표본(모델 구축용)과 운영표본(사후 모니터링용)으로 분리·재현하는
방식으로 검증 프로세스를 시뮬레이션했습니다.

## 데이터
- 08-card-credit-risk와 동일한 대만 카드사 데이터(30,000명)를 개발표본
  21,000명(70%)과 운영표본 9,000명(30%)으로 층화추출 분리(부실비율 양쪽
  모두 22.12%로 동일)
- 모델은 개발표본으로만 재학습(08번과 동일한 XGBoost, scale_pos_weight 적용)

## 방법론
1. **변별력(Discriminatory Power) 검증**: 개발/운영표본 각각의 AUC·KS 비교,
   PD 점수 기준 10분위(Decile) 등급화 후 등급별 실제 부실률의 단조 증가 여부 확인
2. **캘리브레이션(Calibration) 검증**: 등급별 모델 예측 PD 평균과 실제 부실률을
   비교해 예측치의 신뢰도 평가
3. **PSI(Population Stability Index) 검증**: 개발표본 대비 운영표본의 PD
   점수 분포 변화를 10개 구간으로 나눠 정량화

## 주요 결과

| 검증 항목 | 개발표본 | 운영표본 |
|---|---|---|
| AUC | 0.828 | 0.771 (하락폭 6.9%) |
| KS | 0.492 | 0.417 |
| 등급별 부실률 단조성 | 충족 | 미충족(2·3등급 근소 역전, 표본노이즈 수준) |

| 지표 | 값 | 판정 |
|---|---|---|
| PSI | 0.0016 | 안정적 (기준: <0.1 안정) |
| 캘리브레이션 | 전 등급에서 예측 PD가 실제 부실률을 2~3배 과대추정 | **불량** |

## 시사점
- **PSI는 완벽히 안정적**: 무작위 분리 특성상 예상된 결과지만, "실제로 모집단
  변화가 없을 때 PSI가 이렇게 낮게 나온다"는 기준점을 확인함으로써, 향후 실제
  시간 경과 데이터를 검증할 때 비교 기준으로 활용 가능
- **변별력은 양호하나 완전하지 않음**: AUC가 개발표본 대비 운영표본에서
  6.9% 하락해, XGBoost가 개발표본에 어느 정도 과적합되었을 가능성을 시사함.
  다만 등급별 부실률의 전반적인 우상향 추세는 두 표본에서 거의 일치해
  모델의 근본적 순위분별력 자체는 유지됨
- **가장 중요한 발견 — 캘리브레이션 실패**: 모든 등급에서 모델이 예측한
  부도확률이 실제 부실률을 큰 폭(등급에 따라 2~3배)으로 초과함. 원인은
  클래스 불균형 보정을 위해 사용한 `scale_pos_weight` 파라미터로, 이는
  순위 변별력(누가 더 위험한지 판단)을 높이는 대신 예측 확률의 절대값을
  체계적으로 왜곡시킴. **이는 "변별력이 좋다고 캘리브레이션까지 좋은 것은
  아니다"라는 모델검증의 핵심 원칙을 실증적으로 보여주는 사례이며, 이 모델을
  리스크 등급 분류(순위 매기기)에는 사용할 수 있어도, 예측 PD 값을 그대로
  충당금 산출 등에 사용하면 과잉적립으로 이어질 수 있음을 시사함**

## 한계점
- 실제 시간 흐름에 따른 검증이 아닌 무작위 분리로 시뮬레이션한 것으로, 계절성·
  경기순환 등 실제 시간 경과에 따른 모집단 변화는 반영하지 못함
- 캘리브레이션 문제의 해결책(Platt Scaling, Isotonic Regression 등 확률
  보정 기법 적용)은 본 분석의 범위에 포함하지 않았으며 후속 과제로 남김
- 단일 모델(XGBoost)만 검증했으며, 동일 데이터의 로지스틱 회귀 모델과의
  캘리브레이션 비교는 다루지 않음

## 사용 스택
Python (Pandas, NumPy, Scikit-learn, XGBoost, Matplotlib), Kaggle API, Google Colab
