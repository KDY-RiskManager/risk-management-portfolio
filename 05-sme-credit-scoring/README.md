# 05. 가맹점(SME) 신용위험 스코어링 — 재무제표 기반 PD 모델

## 프로젝트 개요
DART(전자공시시스템) Open API로 코스닥 상장 중소기업의 재무제표를 수집하고,
감사의견을 부실 대리지표로 매칭하여 로지스틱 회귀·XGBoost 기반 PD(부도확률) 모델을
구축한 분석입니다. 거래상대방의 재무제표를 근거로 신용위험을 판단하는 실무 프로세스를
공개데이터로 재현하는 데 목적을 두었습니다.

## 분석 배경 및 목적
기존 개인신용 PD 모델(02-credit-risk)과 동일한 방법론을 기업 신용평가로 확장한
프로젝트입니다. 다만 기업 신용평가는 실제 부도 이력 데이터베이스(신용평가사 보유)에
개인이 접근할 수 없다는 현실적 제약이 있어, 공개된 감사의견 정보를 부실의
대리지표(proxy)로 활용하는 방식으로 설계했습니다.

## 데이터
- **대상**: 코스닥 상장법인 중 자산총계 5,000억원 미만 기업(중소기업기본법 시행령
  자산 기준을 준용한 SME 대리표본), 1,220개
- **재무비율**: 부채비율, 유동비율, 영업이익률 (이자보상배율은 공시 커버리지 부족으로
  제외 — 한계점 참고)
- **부실 라벨**: FY2024 사업보고서 감사의견이 "적정"이 아닌 경우(한정의견, 부적정,
  의견거절) 1로 라벨링. 부실 비율 2.79%(34개)

## 방법론
1. DART corpCode API로 전체 상장기업 고유번호 수집 → 법인구분(코스닥) 필터링
2. 재무제표 전체계정과목 API로 FY2023 재무비율 산출, 자산총계 기준 SME 필터링
3. 감사의견 API로 FY2024 라벨 수집·정규화(표기 불일치 처리)
4. 로지스틱 회귀(class_weight='balanced')와 XGBoost(scale_pos_weight 적용)를 학습·비교
5. ROC-AUC, KS statistic으로 모델 성능 평가

## 주요 결과

| 구분 | 값 |
|---|---|
| 모델링 표본 | 1,220개 (부실 34개, 정상 1,186개) |
| 로지스틱 회귀 | ROC-AUC 0.646, KS 0.322 |
| XGBoost | ROC-AUC 0.497, KS 0.166 |
| 부실위험 증가 요인 | 부채비율 ↑ |
| 부실위험 감소 요인 | 유동비율 ↑, 영업이익률 ↑ |

## 시사점
- 로지스틱 회귀 계수의 방향이 경제적 직관과 정확히 일치(부채비율 양수, 유동비율·
  영업이익률 음수)해 모델의 타당성을 뒷받침함
- **XGBoost가 로지스틱 회귀보다 오히려 낮은 성능(AUC 0.497, 사실상 랜덤 수준)을
  보인 점이 중요한 발견**: 부실기업 표본이 34개(학습셋 기준 24개)로 극소수인
  상황에서는 파라미터가 많은 트리 앙상블 모델이 쉽게 과적합되고, 파라미터가 적은
  로지스틱 회귀가 오히려 더 강건함을 실증적으로 확인함. 이는 소표본 신용리스크
  모델링에서 모델 복잡도를 표본 크기에 맞춰 신중히 선택해야 한다는 실무적 시사점을 줌

## 한계점
- 실제 부도 이력이 아닌 감사의견 비적정을 대리지표로 사용 — 실제 부도와는 정의상
  차이가 있으며, 상장 유지요건상 부실기업이 조기에 상장폐지·정리되어 표본에서
  체계적으로 제외될 가능성(생존편향)이 있음
- 부실 표본이 34개로 매우 작아 모델 성능지표의 안정성이 제한적임
- 이자보상배율은 다수 SME가 이자비용을 별도 공시하지 않아 결측치가 92%에 달해
  분석에서 제외함 — 공시 커버리지의 구조적 한계
- 비상장 SME(진짜 가맹점 규모)는 DART 공시 대상 여부가 기업마다 달라 코스닥
  상장기업으로 대리표본을 구성했으며, 실제 가맹점 포트폴리오와는 규모·업종 분포에
  차이가 있을 수 있음

## 사용 스택
Python (Pandas, NumPy, Scikit-learn, XGBoost, Matplotlib), DART Open API, Google Colab

## 작성 노트
코딩 초심자로서, Claude(Anthropic)의 도움을 받아 실무 신용리스크 평가 프로세스를
공개데이터로 재현·학습하는 목적으로 진행한 프로젝트입니다. 데이터 정의, 라벨링 방식,
결과 해석은 직접 판단했으며, 구현은 AI의 도움을 받았습니다.
