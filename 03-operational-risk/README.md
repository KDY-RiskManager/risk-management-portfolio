# 운영리스크(Operational Risk) 분석 — 손실분포접근법(LDA) 및 KRI 모니터링

손실분포접근법(LDA)을 활용해 운영리스크 자기자본을 산출하고, 바젤 기초지표법(BIA)과 비교했으며, 핵심리스크지표(KRI) 대시보드로 사전적 모니터링 체계를 구축한 프로젝트입니다.

## 프로젝트 개요

- **목적**: 운영리스크 손실 데이터를 통계적으로 모델링해 규제자본을 산출하고, 사전 경보 체계(KRI)를 설계
- **분석 방법**: 실제 은행 내부 손실 데이터는 공개되지 않아, 운영리스크의 표준 통계 모델(빈도-포아송, 심도-로그정규)에 기반한 시뮬레이션 데이터로 분석
- **핵심 질문**:
  1. 손실분포접근법(LDA)으로 운영리스크 자기자본을 어떻게 산출하는가?
  2. 정교한 통계모델(LDA)과 단순 지표법(BIA)의 자본 산출 결과는 얼마나 다른가?
  3. 사후적 손실 분석을 넘어, 사전에 위험을 감지할 수 있는 모니터링 체계는 어떻게 설계하는가?

## 사용 데이터

| 항목 | 내용 |
|---|---|
| 데이터 성격 | 운영리스크 표준 통계모델 기반 시뮬레이션 데이터 (10년치) |
| 빈도(Frequency) 모델 | 포아송 분포 (연평균 25건) |
| 심도(Severity) 모델 | 로그정규분포 |
| KRI 데이터 | 24개월치 월별 시계열 (시스템 다운타임, 직원 이직률, 고객불만 건수) |

## 분석 방법론

### 1. 손실분포접근법(LDA)
- 빈도(포아송)와 심도(로그정규) 분포를 결합해 개별 손실 데이터 생성 및 모수 추정

### 2. 몬테카를로 시뮬레이션
- 추정된 분포 모수로 10,000개의 가상 연도를 시뮬레이션해 연간 총 손실 분포 도출
- 95%, 99%, 99.9% 신뢰수준의 연간 손실액(VaR) 산출

### 3. 바젤 기초지표법(BIA)과 비교
- BIA: 최근 3년 평균 총이익의 15%를 자기자본으로 산출하는 단순 방식
- LDA(99.9% VaR) 자본과 비교해 방법론 간 차이 분석

### 4. KRI(핵심리스크지표) 모니터링
- 시스템 다운타임, 직원 이직률, 고객불만 건수 3개 지표에 대해 임계치 설정 및 초과 여부 모니터링

## 주요 결과

### LDA 손실 분포 및 자기자본

| 신뢰수준 | 연간 손실액 |
|---|---|
| 95% | 1,335,634 |
| 99% | 2,462,059 |
| **99.9% (규제자본)** | **4,861,821** |

### BIA vs LDA 자기자본 비교

| 방법론 | 자기자본 |
|---|---|
| BIA (총이익의 15%) | 1,285,000 |
| LDA (99.9% VaR) | 4,861,821 |
| **차이** | **+278.4%** |

### KRI 모니터링 결과 (최근 24개월)

| KRI | 임계치 | 최근 추세 |
|---|---|---|
| 시스템 다운타임 | 5.0시간 | 산발적 초과, 최근 빈도 증가 |
| 직원 이직률 | 8.0% | 임계치 초과 없음, 안정적 |
| 고객불만 건수 | 20건 | 최근 3개월 연속 임계치 초과 (급증) |

## 핵심 인사이트

1. **운영리스크 손실은 전형적인 fat tail 구조를 가진다.** 개별 손실의 중앙값(4,741)과 99% 분위수(360,643) 사이 격차가 76배에 달해, 평상시엔 관리 가능한 수준이지만 드물게 압도적으로 큰 손실이 발생할 수 있는 구조임을 확인했다.
2. **단순 지표법(BIA)은 실제 리스크 프로파일을 과소평가할 수 있다.** 손실 데이터의 빈도·심도를 반영한 LDA 자본이 BIA 대비 278% 더 크게 산출되어, 규모(총이익) 기반의 단순 방식이 fat tail 리스크를 가진 조직의 실제 소요자본을 상당히 과소평가할 수 있음을 정량적으로 보여준다.
3. **KRI는 사후 분석을 보완하는 사전 경보 체계로서 유효하다.** 고객불만 건수가 최근 3개월간 임계치를 연속 초과하며 급증한 반면 이직률은 안정적으로 유지되어, 여러 지표를 함께 모니터링함으로써 특정 리스크 영역(프로세스·시스템)의 조기 악화 신호를 개별적으로 포착할 수 있었다.
