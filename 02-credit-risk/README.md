# 신용리스크(Credit Risk) 분석 — PD 모델링 및 IFRS9 기대손실(ECL) 산출

UCI German Credit Data를 활용해 부도확률(PD)을 예측하는 모델을 구축하고, IFRS9 기준 기대손실(ECL)을 산출한 프로젝트입니다.

## 프로젝트 개요

- **목적**: 개인신용대출 데이터를 활용해 PD 모델을 구축하고, 회계기준(IFRS9)에 따른 기대손실을 정량화
- **분석 대상**: 대출자 1,000명의 신용정보 및 실제 부도 여부
- **핵심 질문**:
  1. 로지스틱 회귀로 부도확률(PD)을 얼마나 정확하게 예측할 수 있는가?
  2. IFRS9 기준으로 Stage를 분류하고 기대손실(ECL)을 어떻게 산출하는가?
  3. 모델이 어떤 변수를 근거로 위험을 판단하며, 그 판단에 한계는 없는가?

## 사용 데이터

| 항목 | 내용 |
|---|---|
| 데이터 소스 | UCI Machine Learning Repository — German Credit Data |
| 전체 대출자 수 | 1,000명 |
| 실제 부도율 | 30.00% |
| 학습/검증 분리 | 70% / 30% (계층화 추출) |

## 분석 방법론

### 1. PD 모델링
- 로지스틱 회귀(Logistic Regression)로 대출자별 부도확률(PD) 산출
- 범주형 변수(신용이력, 저축액, 근속기간 등)는 원-핫 인코딩으로 전처리

### 2. 모델 성능 검증
- **ROC-AUC**: 모델이 부도자와 정상자를 얼마나 잘 구분하는지 평가
- **KS statistic**: 두 그룹의 누적 분포 차이를 측정

### 3. IFRS9 Stage 분류 및 ECL 산출
- PD 20% 이상: Stage 2(신용위험 유의적 증가) → Lifetime ECL 인식
- PD 20% 미만: Stage 1(정상 채권) → 12개월 ECL 인식
- ECL = PD × LGD(45%, 무담보 개인신용대출 표준 가정) × EAD(대출금액)

### 4. 모델 설명력 분석
- 로지스틱 회귀 계수를 통해 부도 위험을 높이거나 낮추는 주요 변수 도출

## 주요 결과

### PD 모델 성능

| 지표 | 값 | 평가 |
|---|---|---|
| ROC-AUC | 0.801 | 우수 (실무 활용 가능 기준 0.7 이상) |
| KS statistic | 0.479 | 우수 (실무 우수 기준 0.4 이상) |

### Stage별 기대손실(ECL)

| Stage | 특징 | 총 기대손실 비중 |
|---|---|---|
| Stage 1 (정상 채권) | 12개월 ECL 적용 | 낮음 |
| Stage 2 (위험 증가 채권) | Lifetime ECL 적용 | Stage 1 대비 약 10배 이상 |

소수의 고위험(Stage 2) 대출자가 전체 포트폴리오 기대손실의 대부분을 차지하는 것으로 확인됨.

### 부도 위험에 영향을 미치는 주요 변수

**위험을 높이는 변수**: 담보 자산 없음, 대출 목적(교육비), 기존 대출 건수, 소득 대비 상환 부담률, 부양가족 수

**위험을 낮추는 변수**: 저축액 1,000DM 이상, 근속기간 4~7년, 무상 거주, 담보 자산(자동차 등) 보유, 공동 채무자 존재

## 핵심 인사이트

1. **PD 모델이 통계적으로 우수한 판별력을 보임.** ROC-AUC 0.801, KS 0.479로 실무 기준을 충분히 상회했다.
2. **IFRS9 Stage 분류가 리스크 집중도를 명확히 드러냄.** Stage 2로 분류된 소수의 대출자가 전체 기대손실의 대부분을 차지해, 리스크관리의 핵심이 "평균 관리"가 아닌 "위험이 커지는 소수를 얼마나 빠르게 식별하는가"에 있음을 확인했다.
3. **모델 해석 결과, 두 가지 유의점을 발견함.**
   - 일부 변수(과거 신용문제 이력)가 반직관적으로 위험을 낮추는 방향으로 나타나, 표본 편중 등 데이터 자체의 한계 가능성을 시사한다. 모델 결과를 그대로 신뢰하기보다 도메인 지식으로 교차 검증할 필요가 있다.
   - 국적 관련 변수가 부도 위험 판단에 유의미하게 반영되어, 실제 신용평가 모델 구축 시에는 공정성(fairness) 관점에서 해당 변수의 사용 여부를 별도로 검토해야 함을 확인했다.
